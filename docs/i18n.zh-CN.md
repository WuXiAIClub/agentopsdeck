# 英文与简体中文

**简体中文 · [English](i18n.md) · [文档目录](README.zh-CN.md)**

支持 `en`、`zh-CN`。主 README 与默认文档为英文；`README.zh-CN.md` 及配套指南
提供简体中文。

## 实现

[`i18n.ts`](../apps/web/src/lib/i18n.ts) 优先使用已保存的偏好，再回退浏览器语言；
采用独立的 `agentopsdeck.locale`，更新文档语言并懒加载中文。
[`translations.ts`](../apps/web/src/lib/translations.ts) 使用英文原文作为类型化键，
保存中文字典；中文加载前回退英文。参数只作纯文本插值，不作 HTML。
用户消息、文件名、供应商诊断、日志不能作为任意翻译键，也不能改写以掩盖错误。

## 检查与贡献

```sh
pnpm check:i18n
node scripts/run-script-tests.mjs check-web-i18n.test.mjs check-i18n-catalog.test.mjs documentation.test.mjs
node scripts/run-source-tests.mjs web lib/i18n.test.ts
```

JSX检查覆盖静态文案、title/placeholder/alt/aria-label和条件回退。精确例外仅用于
产品名、机器命令，不豁免未翻译正文。字典检查覆盖重复/空值、插值参数以及全部
`.ts`/`.tsx` 的字面量 `t`/`translate`/`translateMessage` 调用。
原测试覆盖语言回退、英文原样、安全插值；文档测试覆盖双语配对、导航和安装示例。

新增文案时同时添加英文键与中文值，保留全部参数、复用已有翻译hook并提供
本地化无障碍标签。行为变化同时更新双语指南，不另建语言系统。

## 明确边界

动态键只统计，不声称全部静态验证；还需类型检查和定点功能测试。
服务端/供应商诊断与用户内容不承诺翻译。偏好/存储异常、中文加载失败、换行和
辅助技术渲染仍需真实浏览器测试，源码检查不代表视觉或键盘/触控已验收。

# 使用指南

**简体中文 · [English](user-guide.md) · [文档导航](README.zh-CN.md)**

## 首次登录

完成 [安装](installation.zh-CN.md)，打开对应的开发或编译实例地址，在登录
界面输入私有访问密钥。AOD 是可信操作者应用，不是匿名公共服务。
语言选择保存在浏览器；未主动选择时，中文浏览器语言使用简体中文，其他
语言使用英文。

不同实例请使用不同主机名或浏览器配置；Cookie 不按端口隔离。
截图和支持报告不能包含凭据。

## 连接与智能体

Hub 展示环境，Connector 接入所配置的原生运行时和资源；`all` 模式将两者
放在一个进程中。创建会话前先选对连接和智能体。初始适配器全部关闭，因此
列表为空不代表安装失败；按 [集成指南](integrations.zh-CN.md) 配置专属运行时
和工作区。

连接授权和资源权限仍然有效；成功登录不代表自动获得所有远端环境或任意
本机文件的访问权。

## 会话、消息与工具

1. 在目标连接与智能体下创建或打开会话。
2. 发送任务前确认工作区和执行权限。
3. 查看消息历史与工具条目；它们是观察到的执行记录，不保证供应商成功，
   也不证明没有后台工作。
4. 消息已接受或进入队列后，不要因历史显示稍慢就重复发送；使用现有回执
   与恢复机制。

隐藏和归档只是整理操作，不是取消执行的证明。删除、终止终端等破坏性操作
需单独判断。资源不可用可能是权限不足、未配置或断线，先排查再改权限。

## 状态与恢复

| 状态 | 含义及安全操作 |
| --- | --- |
| 执行中 | 已观察到执行仍活跃；等待，或按已有授权流程中断。 |
| 执行失败 · 可以继续发送消息 | 失败轮次已通过结束、同步和后台工作检查，可发送下一条。 |
| 历史同步失败／未完成 | 消息投影不完整，不能据此认定执行已经停止。 |
| 后台终端仍在运行 | 回合可能结束，但原生工作仍在；需核对归属和清理权限。 |
| 执行状态待核实／`outcome_unknown` | 结果未被证明；不能重发、重放、删除保护或强改为闲置。 |

“恢复会话”按条件出现，不是无条件强制解锁。出现时按界面完成检查与确认，
仍需核对准确执行身份、历史和后台工作。拒绝恢复可能是正确的保护结果。
超时和刷新页面都不是停止证明；需要长期运行的服务不能随便停止。
状态持续异常时参照 [故障排查](troubleshooting.zh-CN.md)。

## 看板、笔记与文件

工作区卡片承载看板、笔记和已授权资源。界面编辑成功不等于文件同步写入
成功；确认文件绑定及同步状态。绑定失败应定位原因，不能通过改活跃数据库
或删除权限记录绕过。

文件浏览、预览和写入受目录配置与授权约束，默认不开放任意宿主机文件。
只配置具体项目目录，不要使用文件系统根目录或其他实例的原生 HOME。

## 请求支持前

记录 AOD 版本／源码修订、受影响连接、状态类别、大致时间和复现步骤。
消息内容、工具参数、标识符和含凭据 URL 需脱敏，公开报告使用合成示例。
联系渠道及私有报告准备要求见 [安全规范](../SECURITY.md)。

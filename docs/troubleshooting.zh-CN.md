# 故障排查

**简体中文 · [English](troubleshooting.md) · [文档导航](README.zh-CN.md)**

先只读检查并准备脱敏复现，不能靠删除状态、重放受保护队列、换密钥或
盲目重启掩盖症状。

| 问题 | 安全下一步 |
| --- | --- |
| pnpm 缺失／版本错 | 检查 Node 要求，准备 pnpm 9.15.0。 |
| 原生编译失败 | 检查 Python／make／C++ 与系统支持，保留锁文件，日志脱敏。 |
| 冻结安装失败 | 确认包管理版本及源码完整，不悄悄重生成锁文件。 |
| 配置工具拒绝 | 已有密钥被保留，使用普通 `.env`，不强制轮换或覆盖。 |
| 外部配置缺失 | 检查绝对 `AOD_CONFIG_FILE` 与服务账号权限，拒绝是预期行为。 |
| 端口占用 | 只读查归属，换空闲 API 端口及对应 Vite 目标，不杀无关进程。 |
| 编译网页不可用 | 确认匹配 shared／web／server 构建，Vite preview 不是生产 API。 |
| 开发 API 失败 | 检查端口与 `AOD_VITE_API_TARGET`，必要时仅重启一次性开发进程。 |
| 没有智能体／会话 | 初始适配器关闭，需准备运行时、连接授权和工作区。 |
| 登录失败 | 检查目标实例／密钥、主机名 Cookie 范围及来源，不泄露密钥。 |
| 登录锁定 | 排查旧凭据、错误实例及限流，不删除认证记录绕过。 |
| 容器不可达 | 检查安装指南的显式地址／端口覆盖，`.env` 会覆盖镜像默认值。 |
| 容器数据无权限 | 检查非 root 卷权限，不能复用其他实例卷。 |
| 文件／预览为空 | 检查最小根目录及授权，初始列表为空是预期行为。 |
| 看板／笔记同步失败 | 区分界面编辑与绑定权限／状态，用受支持 UI／API，不打开活跃 SQLite。 |

## 会话与上游失败

上游 HTTP 400／5xx 表示执行／供应商失败，不能证明线程结束、历史完整或
后台停止。只收集状态类别、时间及合成示例；请求兼容与生命周期分别排查。

1. 确认连接／智能体，区分执行失败、历史同步失败、后台活跃和结果待核实。
2. 已证明结束、历史完整且无后台工作时，可允许下一条消息，不覆盖执行身份。
   对已完成回合遗留本会话归属后台终端（`background-work`）的 Codex 会话，
   当线程可接受输入时允许显式用户跟进消息（压缩与维护仍保持受保护），也可通过
   **结束后台终端**（`POST .../background-terminals/stop`）终止归属的遗留后台终端。
3. 出现恢复操作时（Codex、Claude Code、Copilot 或 Antigravity 的 `POST .../recovery`），
   按检查流程办理；SDK 进程内恢复需先确认物理进程清理完成，并在不重启 Connector
   的情况下释放残留驱动状态。拒绝／409／503 表示运行时证明不可用，不是强制改闲置的许可。
4. 保留已接受／排队回执，丢响应或断线后不重发，旧事件不能当成新执行证明。
5. 保留 `outcome_unknown`，升级准确身份观测；时间经过、历史为空、重启都不是结束证明。
   在 Linux 上，Codex 进程组排空在 `SIGTERM` 宽限 10 秒未退出时会自动升级 `SIGKILL`；
   `PrivateAgentHomeLease` 仅在跨系统重启（内核 `boot_id` 变化）且持久绑定精确匹配时
   自动回收遗留 owner 锁。

另行授权的新会话处理不同任务只是绕行，不算旧会话修好；不能自动重复
可能已执行的业务操作。见 [使用指南](user-guide.zh-CN.md) 与
[运维指南](operations.zh-CN.md)。

## 安全诊断

已安装本机一体化实例可检查：

```sh
node --version
pnpm --version
curl --fail --silent --show-error http://127.0.0.1:8890/api/health
```

端口改变时用实际配置；健康不是执行／供应商验收。源码问题运行相关
[开发测试](development.zh-CN.md)，不能针对活跃运行状态。
报告版本／修订、平台、角色、脱敏类别及准确步骤，不附 `.env`、数据库、
原生 HOME、历史、Token 或原始上游请求。敏感报告先确认私有渠道，见
[安全规范](../SECURITY.md)。

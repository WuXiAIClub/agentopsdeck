AgentOpsDeck (AOD) 1.0.0 is a source-first, self-hosted agent operations deck.
Start with the all-in-one instance; enable native execution only after reviewing
its permissions. No public image, installer or GitHub repository is assumed here.

## Reading routes

- First-time operator: installation → user guide → configuration → troubleshooting.
- Execution operator: security → integrations → operations, before enabling tools.
- Contributor: development → contributing → upstream synchronization.
- Release maintainer: license status → validation record → operations; publication
  and deployment each require explicit authorization.

Commands assume the repository root unless stated otherwise. Examples contain no
credentials. Runtime settings, native homes, histories and backups belong outside
publishable source. English and Simplified Chinese guides describe the same scope.

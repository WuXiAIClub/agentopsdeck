# 开源化代码审查规范

**简体中文 · [English](open-source-review-standard.md)**

这是 AgentOpsDeck 1.0.0 及后续上游补丁的审查约定，不是发布批准。先读仓库指令、
[安全规则](../SECURITY.md)、[许可状态](../LICENSE-STATUS.md)及
[上游规则](upstream-sync.md)。

## 范围与证据

用 `git ls-files --cached --others --exclude-standard -z` 枚举可发布的已跟踪和
未跟踪文件，去重排序，不为枚举而暂存。排除忽略的依赖、产物、私有溯源/设置和
运行状态。禁止打开活跃数据库、暴露凭据/业务历史、访问私有提供商、重启服务或
重放结果未知的执行。

划分互不重叠的模块。每个文件记录相对路径、SHA-256、大小、类型、深度、检查、
具体观察及问题编号。哈希变化使记录失效，新增文件也需审查。报告快照大小、
分工、缺失/重复记录及过期哈希。

- `semantic`：完整检查文件及相关调用/约定/测试，备注说明检查和限制。
- `structural`：检查语法、元数据、模式或测试结构，**不是**完整语义/安全批准。
- `asset`：识别二进制/生成资源，在证据范围内查来源/许可/暴露面；读字节不等于看图。
- `pending`：未审或证据不足，注明原因。

结论为 `no-finding`、`finding`、`pending`、`not-applicable`。未发现问题仅适用于
注明深度，不是安全证明。搜索、扫描、自动表格、测试、依赖清零均不能代表完整
逐文件语义审查。测试、生成清单、原生骨架、资源需与运行代码分别统计。

公开台账为 `docs/review/file-review.json`。`pnpm check:review` 校验覆盖、哈希和
证据格式，不代表语义审查全部完成；`pnpm check:review:complete` 还会拒绝结构级/
待审证据及未解决问题。仅台账本身不纳入自己的哈希枚举，避免自引用；台账的
JSON 格式仍被验证，字节仍参加发布扫描。两条命令均不授权发布。源码变化必须
实际复审，不能仅批量刷新哈希。

## 必查项目

| 领域 | 检查 |
| --- | --- |
| 包/供应链 | 全部 manifest、工作区、engine/peer、声明与锁定版本、运行/构建分类、生命周期脚本、限定覆盖、registry 来源、冻结安装、不可变/只读 CI；禁压制审计，明确生产/开发范围。 |
| 隐私/可移植性 | 禁前身品牌、固定私有目录/域名/网络默认值、凭据、历史、环境专有部署回执；独立 `AOD_*` 设置有文档，夹具/生成文件/资源也检查。 |
| 认证/授权 | HTTP/WebSocket/流式入口失败时拒绝；Origin/CSRF/Cookie/通行密钥、签发者版本/授权/撤销、所有者/成员、读/写隔离；追踪入口到操作。 |
| 不可信输入 | 路径规范化/授权防穿越/符号链接/编码绕过；请求体/帧/集合/时间/并发上限；SSRF/重定向、HTML/Markdown/URL、shell/参数注入、上传/归档、错误/日志脱敏。 |
| 执行/恢复 | 精确身份、终态单调、旧事件拒绝、断线恢复、取消/清理、证明完成后续接、维护围栏；超时非停止证明，保护 `outcome_unknown`。 |
| 存储/文件 | 事务/迁移、原子写入、权限/备份、独立目录、保留上限、权限连续性/文件绑定修复；测试仅可销毁状态。 |
| UI/i18n | 不安全渲染、焦点/键盘/触控/无障碍、监听/计时器清理、并发、中英动态键和非 JSX 标签；复用菜单架构，不统一延迟。 |
| 原生/工具 | 下载/安装/构建、归档路径、权限/服务边界、平台设置、签名、子进程输出/用户设置；实验骨架不能叫已验收发行物或沙箱。 |
| API/文档 | 示例与代码一致、中英约定一致、认证/请求体/错误/流式有文档；路由清单不等于完整 OpenAPI 或已部署 Swagger。 |
| 许可/发行物 | 继承源码分发权、资源来源、第三方声明、准确版本与最终源码/web/镜像/原生分别审查；Apache-2.0 和新作者不代表第三方所有权。 |

## 问题与验证

每项问题有编号、严重度（`critical`、`high`、`medium`、`low`、`info`）、路径/行号、
证据、信任边界、真实触发/影响、最小修复、回归或缺口。猜测必须标注；敏感值
脱敏。沿用架构，委派写范围不重叠；审查者只写指定报告，另授权才修代码。
禁止吞错、削弱断言、压制审计、虚构法律批准以通过门槛。

沿用隔离运行器，先相关回归，再构建/类型检查/广泛测试，记录选择器/数量/失败/
排除项。本机成功不代表远端 CI。真实浏览器/触控、提供商、原生/平台、容器另需
证据。最低源码门槛包含：

```sh
pnpm check:publication
pnpm check:i18n
pnpm check:api
pnpm audit --prod --json
NODE_ENV=development pnpm audit --json
```

还需冻结安装和脚本/web/后端测试。这些必要但不充分，分别报告深度、风险、实际
测试、权利、发行声明和授权。审查不授权提交、推送、tag、生产重放或部署。

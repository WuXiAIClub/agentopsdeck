# 运维、备份与升级

**简体中文 · [English](operations.md) · [文档导航](README.zh-CN.md)**

这是操作者清单，不是已执行部署；不会安装服务或重启宿主。
先读 [安全规范](../SECURITY.md) 和 [验证范围](validation-1.0.0.md)。

## 独立运行目录

已审查的不可变代码／构建与私有配置、可变状态分开。由管理员另行准备的
示例路径：

```text
/opt/agentopsdeck/releases/<reviewed-revision>/  对应修订的源码与构建
/etc/agentopsdeck/server.env                   私有配置
/srv/agentopsdeck/data/                        数据库、队列及状态
/srv/agentopsdeck/codex-home/                  可选原生 HOME
/srv/agentopsdeck/workspace/                   已授权项目工作区
```

使用专属非 root 账号，盘点数据根外的其他原生 HOME、委托文件及项目目录。
禁止用其他活跃实例状态初始化 AOD。后续本机实例与 GitHub／GitLab 镜像应
对应同一已审查的不可变 AOD 提交，运行设置放在提交外。

完成构建和完整外部配置后，可在发布根目录以前台方式启动：

```sh
AOD_CONFIG_FILE=/etc/agentopsdeck/server.env node apps/server/dist/index.js
```

示例文件必须存在，包含私有密钥、独立路径及关闭或明确配置的适配器。
这不是针对现有生产服务的操作指令。服务管理器需要另行审查账号、单元、
工作目录、环境和关闭策略；草稿不提供自动服务安装／更新。

## 远程访问清单

- 优先回环监听加自有 TLS 反向代理，不能将开发或预览监听器当生产入口。
- 设置 `AOD_PUBLIC_BASE_URL`、精确允许来源及自有可信代理；不信任任意
  客户端 forwarded 头。
- 保留认证、流式长响应及使用到的 WebSocket upgrade，不记录密钥或认证 Cookie。
- 独立认证实例使用不同主机名，限制网络访问并审查文件／资源授权。
- 构建期来源改变后重建网页，从每个真实来源检查资源、登录、流式消息、
  重连及权限拒绝。

不声称有通用且已验收的生产代理配置。Passkey、安全上下文及实际网络／
代理环境需另行验证。

## 备份与恢复

1. 盘点数据、每文件覆盖、原生 HOME、委托文件和工作区，包含默认目录外的根。
2. 取得维护授权，按已有流程暂停新任务，证明准确执行结束及后台工作状态；
   结果未知仍受保护，无可见会话不等于闲置证明。
3. 智能体若托管于待维护服务，停启只能由外部独立维护单元执行，禁止直接
   停止自己的宿主。
4. 证明停机后完整备份并校验配置根、私有设置、秘密及对应代码／构建元数据，
   在 Git 外加密或限制访问；打开／复制活跃 SQLite 文件不是一致备份流程。
5. 在关闭执行、无上游重放的隔离实例中测试恢复，保留密钥库秘密及授权；
   恢复的受保护队列不能自动重发工作。

备份可能含供应商凭据和业务历史，不能附在公共 issue 或随源码发行。

## 升级与回退

- 在独立候选目录准备已审查 AOD 修订，按锁文件安装、构建，运行发布扫描、
  文档及相关测试，并记录真实证据。
- 保留外部配置、原生 HOME 和队列，不对已有密钥初始化；迁移先在停机的
  一次性副本验证。
- 取得独立维护／闲置证明并备份后整体切换匹配代码和构建，不混用新 API 与旧网页。
- 按适用范围验收版本／修订、登录、来源与资源、授权、文件同步及原生／会话恢复；
  HTTP 健康不等于整体通过。
- 失败后不盲目重跑一次性控制器，不用旧状态覆盖新工作。授权回退前证明
  数据兼容与执行结果，必要时恢复匹配的代码／数据组合。
